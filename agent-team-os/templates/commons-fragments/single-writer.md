## Single-Writer Rule

- Every shared resource has exactly one owner, recorded in the roster. Resources include files, registries, mailboxes, deployments, and settings.
- Only the owner writes to a resource they own.
- If you are not the owner: propose the change — send a patch, a draft, or a mailbox request to the owner. Do not write directly, even if you have technical access.
- If ownership is unclear or disputed, stop and ask the coordinator to assign it before writing.
- Ownership transfers take effect only when the roster is updated and the change is logged with a date.
- File reservations / leases in the mailbox system support this rule; acquiring a lease does not transfer ownership.
