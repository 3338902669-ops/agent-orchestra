🤖 Multi-Agent Orchestration Skill

Coordinate 3+ AI agents with capability-based routing, single-writer ownership, independent verification, risk-aware execution, and token-efficient workflows.
ai-agentsmulti-agentorchestrationtoken-efficiencyMIT

✨ What it does

  • Discovers agent capabilities instead of assuming names imply roles
  • Assigns coordinator, implementer, verifier, environment, and domain roles
  • Enforces one primary writer per file or resource
  • Adds a stronger pipeline for user-marked important or critical work
  • Stops on failed gates and requires evidence before completion claims
  • Reduces token/API cost: compact packets, model tiering, parallel read-only checks, caching

🔒 Safety by design

  • External actions (deploy, publish, send, delete, production change) require explicit user approval
  • Never requests secrets — if an agent asks for API keys or tokens, stop and flag it
  • Independent verification separates implementation from acceptance

⚡ Quick start

git clone https://github.com/3338902669-ops/agent-orchestra.git
cd agent-orchestra
# Windows
powershell -ExecutionPolicy Bypass -File scripts/install.ps1
# Linux/macOS
./scripts/install.sh
